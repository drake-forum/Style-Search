# Style Search v1.0.1

This release adds a standalone Windows x64 executable alongside the full installer ZIP.

## Downloads

- `Style-Search-v1.0.1-win-x64.exe`: portable, self-contained app with its logo assets embedded.
- `Style-Search-v1.0.1-win-x64.zip`: app plus install/uninstall scripts, shortcuts, and documentation.

The app is not code-signed, so Windows SmartScreen may show a first-run warning. Clipboard history is stored locally as readable text; details are in the README privacy section.
