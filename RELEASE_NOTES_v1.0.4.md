# Style Search v1.0.4

Restores the original v1 visual theme and its rounded, screenshot-based glass composition. This removes the later DWM live-backdrop implementation and its dark rectangular background plate.

The v1 composition intentionally uses a static snapshot behind the search pill. Video and other moving content behind the pill will therefore not update until the launcher is closed and opened again.

Includes a standalone self-contained Windows x64 executable and the full installer ZIP.
