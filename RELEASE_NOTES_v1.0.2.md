# Style Search v1.0.2

This release fixes video and other moving desktop content appearing frozen behind the launcher. The launcher now uses Windows Desktop Window Manager's live acrylic backdrop on supported Windows 11 builds, with the native acrylic fallback on older Windows versions. It no longer captures a static screenshot of the desktop when opening.

Both a standalone self-contained Windows x64 executable and the full installer ZIP are attached. The standalone executable includes its logo assets.

The app is not code-signed, so Windows SmartScreen may show a first-run warning. Clipboard history is stored locally as readable text; details are in the README privacy section.
