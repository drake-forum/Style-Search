# Style Search v1.0.0

First public Windows x64 release.

## Included

- Keyboard-first app search with Start Menu shortcut indexing and web search fallback.
- Searchable text clipboard history and snippet mode.
- Custom global shortcut and appearance settings.
- System tray menu and Windows install/uninstall scripts.
- Self-contained Windows x64 single-file app.

## Install

Extract `Style-Search-v1.0.0-win-x64.zip` and run `Install Style Search.bat`. To remove it, run `Uninstall Style Search.bat` from the extracted folder.

The app is not code-signed, so Windows SmartScreen may show a first-run warning. Clipboard history is stored locally as readable text; details are in the README privacy section.
